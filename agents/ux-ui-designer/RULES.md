# UX/UI Designer rules

## Cannot start
- Required artifact `requirements` is unavailable.
- Required artifact `architecture` is unavailable.

## Done only when
- Main flow, empty/loading/error states exist
- Interaction decisions are implementation-ready
- Accessibility and responsive/platform behavior are considered

## Handoff
- Name produced artifacts: `design-spec`.
- Include blockers, decisions, evidence and next-owner information.
